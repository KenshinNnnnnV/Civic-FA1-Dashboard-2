# Civic FA1 Dashboard v1.0.3

## Runtime UI migration

- Replaced the three runtime artwork resources with the newly approved Connect, Sport and Diagnostics dashboards.
- Connect, Sport and Diagnostics remain three independent dashboards.
- Unified header remains runtime-rendered and removes clock/Wi-Fi from the approved header.
- Unified bottom navigation is runtime-rendered with fixed geometry; only the active accent changes.
- Sport uses the colored RPM arc as the only graphical RPM indicator; no tach needle is rendered.
- Five Sport sensor cards remain tappable and their selected sensors persist in SharedPreferences.
- Demo values baked into the reference artwork are neutralized in the runtime resources and replaced by live overlays.
- Connect touch zones were remapped to the new Connect dashboard layout.
- Manual-launch behavior from v1.0.1 remains unchanged.
- OBD/ELM327 transport and parser logic was not redesigned in this release.

Version: 1.0.3 (versionCode 28)
