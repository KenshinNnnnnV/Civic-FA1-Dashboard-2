# Civic FA1 Dashboard v0.9.4

Base: v0.9.3 architecture and OBD stack.

## UI
- Keeps CONNECT, SPORT and DIAGNOSTICS as three independent dashboards.
- New approved 1280x720 runtime artwork for all three modes.
- SPORT tachometer has no needle.
- SPORT neutral artwork contains no illuminated RPM arc while ECU is disconnected.
- Runtime RPM arc fills from 0 to current RPM: green to 4000 rpm, yellow above 4000 rpm, no red arc.
- Existing white tachometer numerals/ticks remain part of the locked artwork.
- Mode-specific bottom navigation hit zones match the approved layouts.

## Performance
- UI frame coalescing targets ~60 FPS while visible/animating (`UI_FRAME_MS=16`).
- Telemetry publication is capped around 30 Hz when adapter/ECU throughput allows it.
- SPORT polling priority: RPM 90 ms, throttle 120 ms, speed 140 ms, load 160 ms.
- Fair due-time scheduler prevents fast SPORT PIDs from starving slower sensors.
- Removed hot-path RectF/array allocations and repeated clock Date allocation from telemetry frames.
- Static artwork/Paint/Path/geometry objects are cached.
- Removed per-frame recreation of 41 tachometer tick lines; neutral ticks are baked into artwork.

## Lifecycle
- No BOOT_COMPLETED receiver, WorkManager, JobScheduler or AlarmManager autostart path.
- Minimizing/Home does not call `ObdManager.suspend()` or disconnect the active OBD session.
- MainActivity uses `singleTask` to bring the existing dashboard/session back instead of creating a duplicate session.
- Full OBD shutdown remains tied to Activity destruction/process shutdown.
