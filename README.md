# Civic FA1 Dashboard v0.4.0

Honda Civic FA1 Android dashboard (1280x720 landscape).

## v0.4.0
- Unified bottom tabs: identical geometry in Street / Sport / Diagnostics.
- Street active glow: green.
- Sport active glow: light red.
- Diagnostics active glow: cyan.
- Sport tab no longer changes layout height.
- Diagnostics visual restored to the cleaner v0.3.3 design.
- Live numeric values remain dynamic.
- OBD connection selector: AUTO / BLE 4.0 / BT 3.0 Classic / Wi-Fi ELM327.
- BLE/Classic ELM327 live polling for RPM, speed, coolant, throttle, load, intake, MAF, fuel level and adapter voltage.
- Wi-Fi ELM327 transport included (default 192.168.0.10:35000).
- Simulator remains available if no adapter is connected.

### Vgate iCar Pro BLE 4.0 DUAL
Choose **BLE 4.0** first. If needed, try **BT 3.0** after pairing the adapter in Android Bluetooth settings.

> Live OBD transport is hardware/firmware dependent and must be verified on the actual head unit and adapter.
