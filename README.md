# Civic FA1 Dashboard v0.4.1

Полная переработка интерфейса под референс v0.4.1.

## Главное
- Street / Sport / Diagnostics имеют одинаковую геометрию 1280×720.
- Street подсвечивается зелёным, Sport красным, Diagnostics бирюзовым.
- Убраны надписи `DRIVE A BETTER TOMORROW` и `CIVIC FA1 TYPE R` из нового дизайна.
- Нет случайных/симулированных показаний.
- Пока ECU не подтверждён, живые поля показывают `--` / `N/A`.
- После подключения показываются только данные, пришедшие из OBD.
- При потере соединения значения очищаются, а не продолжают меняться.

## OBD
Поддерживаются варианты:
- AUTO
- BLE 4.0 (рекомендовано для Vgate iCar Pro BLE 4.0 DUAL)
- Bluetooth Classic / BT 3.0
- Wi-Fi ELM327
- Disconnect

ELM327 считается подключённым к ECU только после получения корректного ответа `41xx` на реальный PID. Добавлен таймаут команд, чтобы приложение не зависало бесконечно при молчащем адаптере.
