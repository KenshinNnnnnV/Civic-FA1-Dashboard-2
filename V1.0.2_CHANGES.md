# Civic FA1 Dashboard v1.0.2

## Sport tachometer
- No tachometer needle/pointer/endpoint marker.
- The illuminated 0–8000 RPM arc is the only graphical RPM indicator.
- Arc fill follows live ECU RPM with visual smoothing only.
- 0–4000 RPM: green.
- 4000–5500 RPM: yellow.
- 5500–8000 RPM: red.
- At higher RPM the earlier color zones remain filled, so 7000 RPM shows green + yellow + red up to the live value.
- Center RPM number remains the latest truthful ECU sample.

## Configurable Sport widgets
- Five Sport sensor cards remain tappable.
- Tapping a card opens Select Sensor.
- Selection is saved per slot in SharedPreferences (`sport_slot_0` ... `sport_slot_4`).
- Layout/size/position of the card does not change when its sensor changes.
- Once ECU PID capabilities are known, unsupported sensors remain visible as N/A but cannot be assigned.

## Preserved
- CONNECT, SPORT and DIAGNOSTICS remain independent dashboards.
- Common top header and bottom navigation geometry is unchanged.
- Manual-launch behavior from v1.0.1 is preserved.
- OBD/BLE/Classic/Wi-Fi transport logic is unchanged.
